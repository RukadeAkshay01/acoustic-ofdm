Signal Processing Mini Project

Acoustic OFDM Link Bench

An adaptive, self-calibrating OFDM modem that moves files between the speaker and microphone of ordinary consumer devices, in the 4–12 kHz audio band. This bench shows the complete signal chain and every measurement behind it.

Updated 25 Sep 2026 · new: convolutional error correction, sample-clock drift correction and two-device test tooling — see section 05

01

System parameters

Every constant is derived from one place (ofdm/config.py) so that experiments can sweep the design without touching the DSP. The band starts at 4 kHz because laptop speakers roll off badly below it, and stops at 12 kHz because that is where the microphone response falls away on the test hardware.

Transmit power budget — peak-to-average reduction

A speaker is peak-limited, so the figure that sets received SNR is average power at a fixed peak. An unclipped OFDM block throws away about 11 dB of that budget. Clipping the waveform and re-filtering it back into the band buys the power back, until the distortion it introduces starts costing more than the power gains.

02

The signal chain, end to end

A single simulated transmission at 18 dB SNR through a multipath room with a 60 ppm sampling-clock offset — the cross-device case. Each panel is one stage of the receiver, in the order the receiver runs them.

1 · Transmitted waveform

Chirp preamble, then the OFDM burst. The two are scaled separately: OFDM has a 9 dB peak-to-average ratio, so one global normalisation would leave the chirp far too quiet to detect.

2 · Received waveform

After the room, the transducers, noise and an unknown arrival delay.

3 · Synchronisation — matched filter

Correlating against the known chirp. A 30 ms sweep across 10 kHz has a time–bandwidth product near 300, so the peak stays sharp well below 0 dB SNR.

4 · Transmit spectrum

Occupied band after the IFFT. Energy outside 4–12 kHz is the cyclic-prefix discontinuity and the clipping used for peak reduction.

5 · Estimated channel response

Least-squares estimate from the reference symbol, per subcarrier. The nulls are what make equalisation necessary — and what set the error floor.

6 · Per-symbol phase correction

Common phase error removed by the adaptive tracker each symbol. The steady ramp is the sampling-clock offset between the two devices.

7a · No equalisation

The channel's own phase rotation, uncorrected.

7b · Static equalisation

One estimate from the reference symbol, held for the whole burst.

7c · Adaptive equalisation

Pilot-tracked, with per-symbol phase correction.

03

Bit error rate

Each point is 16 independent transmissions of 6 200 bits — about 99 000 bits per point. Every SNR point in a sweep sees the same set of simulated rooms, so differences between points come from noise alone. Points at the floor line had zero errors in all 99 000 bits.

Modem validation — AWGN only

With multipath switched off the measured curve should sit on the coherent-QPSK theory curve. It does, which says the IFFT, cyclic prefix, synchroniser and demapper are all correct.

Equaliser comparison — multipath channel

The headline Phase 2 result. Without equalisation the link never works at any SNR; with it, BER falls until it hits the floor set by the channel's deepest spectral null.
